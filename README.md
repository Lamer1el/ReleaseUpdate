Skitefi — приложение для тестирования производительности Android-устройств.

Добро пожаловать в официальный репозиторий релизов Skitefi! Здесь публикуются новые версии приложения, описания обновлений и исправления ошибок.

О приложении

Skitefi предназначен для проверки производительности смартфона и изучения его характеристик.

Основные возможности приложения:

- CPU Benchmark — тестирование производительности процессора.
- GPU Benchmark — измерение графической производительности.
- RAM Benchmark — тестирование операций с оперативной памятью.
- Storage Benchmark — проверка производительности накопителя.
- Stability Test — наблюдение за изменением производительности при продолжительной нагрузке.
- Battery Test — наблюдение за расходом заряда во время тестирования.
- Display Test — информация о характеристиках экрана.
- История результатов — просмотр и сравнение предыдущих тестов.
- Персонализация — темы, акцентные цвета, шрифты и другие настройки интерфейса.
- Обновления — получение информации о новых версиях приложения.

Skitefi создаётся с акцентом на Material You, удобство использования и понятное представление результатов.
